QUICK START (30 SECONDS)
═══════════════════════════════════════════════════════════════════════════════

1. Prepare images
   $ mkdir ~/my_images
   $ cp /path/to/*.jpg ~/my_images/

2. Process images
   $ python image_to_training_data.py ~/my_images -o ./my_data -v

3. Train network (in Python)
   from FastCGHNet import train_cgh_network
   train_cgh_network(
       use_quantized_data=True,
       quantized_data_dir="./my_data",
       num_epochs=20
   )

═══════════════════════════════════════════════════════════════════════════════

  → Check folder exists and has supported formats

Memory errors?
  → Process in smaller batches

Wrong dataset format?
  → Make sure to use use_quantized_data=True parameter
