📋 PREPARATION (Development Machine)
─────────────────────────────────────────────────────────────────────────────

1️⃣  Export Model to ONNX:

    python -c "
from FastCGHNet import export_onnx
export_onnx('models/best_model_lite.pt', 'models/fastcghnet_lite.onnx')
    "

2️⃣  Test on Development Machine:

    python kria_predict.py test_image.png \
      --model models/fastcghnet_lite.onnx \
      --output test_output.bmp


🚀 DEPLOYMENT (KRIA Board)
─────────────────────────────────────────────────────────────────────────────

1️⃣  Copy Files to KRIA:

    scp models/fastcghnet_lite.onnx root@kria:/root/
    scp kria_predict.py root@kria:/root/
    scp requirements-kria.txt root@kria:/root/

2️⃣  Setup KRIA (First Time Only):

    ssh root@kria bash setup_kria.sh

    Or manually:
    ssh root@kria
    $ pip install onnxruntime opencv-python numpy pillow
    $ exit

3️⃣  Run Inference:

    ssh root@kria python /root/kria_predict.py /root/image.png \
      --model /root/fastcghnet_lite.onnx \
      --output /root/hologram.bmp

4️⃣  Copy Results Back:

    scp root@kria:/root/hologram.bmp ./
